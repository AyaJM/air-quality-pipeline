# 🌍 Air Quality Cloud Pipeline

## 🚀 Overview
End-to-end data pipeline using:
- Azure Blob Storage
- Python (ML + preprocessing)
- Docker
- Kubernetes
- Jenkins
- Streamlit dashboard

## 📊 Features
- Data ingestion from Azure
- ML prediction (Random Forest)
- Automated pipeline (CI/CD)
- Interactive dashboard (Plotly)

## ⚙️ Tech Stack
Python, Azure, Docker, Kubernetes, Jenkins, Streamlit
